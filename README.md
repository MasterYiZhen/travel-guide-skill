# Travel Guide Skill

把旅行想法推进为经用户确认的行程和以图片为主、适合手机查看的旅行攻略，完成独立审核、修复、用户验收与最终交付。支持目的地未知或已知，由用户显式调用，适用于全新、连续的旅行任务。

当前候选：**v0.1.0-rc.5**。

- [运行指令](SKILL.md)与[调用策略](agents/openai.yaml)：唯一可编辑的运行时源码。
- [行为场景](evals/evals.md)与[本版检查记录](evals/results-v0.1.0-rc.5.md)：要求覆盖、方法、结果及未验证范围。
- [安装与更新](docs/chatgpt-cloud-installation.md)：包结构、版本规则和更新步骤。
- [当前安装 ZIP](dist/upload/travel-guide-skill-v0.1.0-rc.5.zip)：与当前源码一致的两文件安装包。

## 验证状态

本版将全天动线、复杂景点内部动线及用餐连续性融入现有标准、研究、制作与审核，沿用八步流程和用户验收机制。验证分层记录：

- **规则与文本场景：** 完成三项要求覆盖检查、E11—E14 文本推演及 E01—E10 回归。
- **实际工具执行：** 完成结构、调用策略、链接、格式和安装包一致性检查；不代表旅行研究、制图或 Reviewer 已实际运行。
- **真实旅行任务效果：** 尚未执行，待安装后的完整旅行任务检验动线和用餐能否从成品理解并执行，以及图片质量、独立审核修复和用户验收；现场效果以实际使用反馈为依据。

详细方法和证据见本版检查记录；本地文件、Git 提交、远端发布和云端安装状态分别记录。
