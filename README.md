# Travel Guide Skill

把旅行想法推进为经用户确认的行程和以高清竖向图片为主、适合手机查看的旅行攻略，完成独立审核、修复、用户验收与最终交付。支持目的地未知或已知，由用户显式调用，适用于全新、连续的旅行任务。

当前候选：**v0.1.0-rc.9**。

- [运行指令](SKILL.md)与[调用策略](agents/openai.yaml)：唯一可编辑的运行时源码。
- [行为场景](evals/evals.md)与[本版检查记录](evals/results-v0.1.0-rc.9.md)：要求覆盖、方法、结果及未验证范围。
- [安装与更新](docs/chatgpt-cloud-installation.md)：包结构、版本规则和更新步骤。
- [当前安装 ZIP](dist/upload/travel-guide-skill-v0.1.0-rc.9.zip)：与当前源码一致的两文件安装包。

## 验证状态

本版把默认详尽讲解、图文融合和实际成品检查写成产品标准，合并重复的时间预算与用餐规则，补清限定范围修复、带保留验收、获取端交付和流程结束条件。沿用八步流程、行程有效确认、每轮全新独立 Reviewer、默认图片规格和两文件运行时安装包。

验证分开记录静态规则检查、独立模型响应、实际图片审核、模拟验收和实际工具执行；云端交付本轮未执行，只记录状态。方法、结果、证据与未验证范围见[本版检查记录](evals/results-v0.1.0-rc.9.md)，原始验证材料保存在 `evals/artifacts/v0.1.0-rc.9/`，不进入运行时安装包。本轮实施环境没有模型图片生成或编辑能力，也没有云端安装渠道；完整候选的正式审核、栅格修复与复审复用 rc.8 历史五页天坛候选（三轮全新 Reviewer，最终系统 PASS 并模拟带保留验收）；rc.9 自行制作图片的效果、真实用户验收、云端下载和现场效果保留未验证状态。

本地文件、Git 提交、远端发布和云端安装分别记录。
