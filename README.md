# Travel Guide Skill

把旅行想法推进为经用户确认的行程和以图片为主、适合手机查看的旅行攻略，完成独立审核、修复、用户验收与最终交付。支持目的地未知或已知，由用户显式调用，适用于全新、连续的旅行任务。

当前候选：**v0.1.0-rc.8**。

- [运行指令](SKILL.md)与[调用策略](agents/openai.yaml)：唯一可编辑的运行时源码。
- [行为场景](evals/evals.md)与[本版检查记录](evals/results-v0.1.0-rc.8.md)：要求覆盖、方法、结果及未验证范围。
- [安装与更新](docs/chatgpt-cloud-installation.md)：包结构、版本规则和更新步骤。
- [当前安装 ZIP](dist/upload/travel-guide-skill-v0.1.0-rc.8.zip)：与当前源码一致的两文件安装包。

## 验证状态

本版明确默认详尽讲解和图文融合标准，合并重复规则，补清限范围修复、带保留验收、获取端交付和流程结束条件。沿用八步流程、每轮全新独立 Reviewer、默认图片规格和两文件运行时安装包。

验证区分规则检查、独立模型响应、实际研究与图片制作、视觉审核、工具及渠道检查和用户验收。方法、结果、证据与未验证范围见[本版检查记录](evals/results-v0.1.0-rc.8.md)，原始验证材料保存在 `evals/artifacts/v0.1.0-rc.8/`，不进入运行时安装包。模拟用户和本地故障服务的结果不代表真实旅行验收、云端下载或现场效果。

本地文件、Git 提交、远端发布和云端安装分别记录。
