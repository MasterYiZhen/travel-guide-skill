# Travel Guide Skill

把旅行想法推进为经用户确认的行程和以图片为主、适合手机查看的旅行攻略，完成独立审核、修复、用户验收与最终交付。支持目的地未知或已知，由用户显式调用，适用于全新、连续的旅行任务。

当前候选：**v0.1.0-rc.7**。

- [运行指令](SKILL.md)与[调用策略](agents/openai.yaml)：唯一可编辑的运行时源码。
- [行为场景](evals/evals.md)与[本版检查记录](evals/results-v0.1.0-rc.7.md)：要求覆盖、方法、结果及未验证范围。
- [安装与更新](docs/chatgpt-cloud-installation.md)：包结构、版本规则和更新步骤。
- [当前安装 ZIP](dist/upload/travel-guide-skill-v0.1.0-rc.7.zip)：与当前源码一致的两文件安装包。

## 验证状态

本版将首轮实物参考、逐页生成与修订结果核对、规格早检融入现有制作、审核和交付，沿用八步流程并加强交付后复盘的场景覆盖。默认参考尺寸允许同等比例的小幅偏差，保留清晰可读的原生输出；用户明确要求精确像素时严格遵守。验证分层记录：

- **规则与文本场景：** 完成本版要求覆盖检查、E16—E18 与 E10 扩展文本推演及 E01—E15 回归。
- **实际工具执行：** 完成结构、调用策略、链接、格式和安装包一致性检查；不代表旅行研究、制图或 Reviewer 已实际运行。
- **真实旅行任务效果：** 本版尚未执行，待安装后的完整旅行任务检验首轮器形准确性、局部一致性、生成失败发现时点、候选及打包一致性、实际规格与返工情况，并记录独立审核修复和用户验收；现场效果以实际使用反馈为依据。

详细方法和证据见本版检查记录；本地文件、Git 提交、远端发布和云端安装状态分别记录。
