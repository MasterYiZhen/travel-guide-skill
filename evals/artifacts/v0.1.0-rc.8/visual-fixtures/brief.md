# 虚构展馆测试页：正确资料与视觉目标

本任务是视觉教学攻略素材检查。两份 PNG 都是虚构测试资料，不对应真实展馆、真实文物或真实旅游候选。

## 唯一资料依据

- 展馆四站按单向顺序相连：南门 → 青铜展区 → 陶器展区 → 北门。
- 虚构展品名称是“三足器甲”。
- 三足器甲具有且仅具有三足、两耳、圆腹，无铭文。
- 全貌与双耳局部应当表现同一器物，局部图的指引应当对应所讲的部件。
- 所有讲解只涉及上述造型。不提供年代、历史、用途等事实。

## 目标

制作手机可读的 3:4 竖版中文图文教学页，清晰标记“虚构展馆测试页”与虚构资料边界。图中包含可见路线示意、四站名称和方向箭头、器物全貌、同一器物双耳局部，以及数足、看耳、看腹的观察解释，文字约 200 字。

路线图像与文字应当有明确对应；器物部件数量与指引位置应当符合资料；中文应当清晰、准确、无错字和异常字形；同级模块字号与字体风格协调。图文自然融合，允许使用合适的文本框。画面应当完整，局部没有妨碍观察的涂抹、接缝或遮挡损伤。

审核以实际 PNG 所见为依据，并区分明确可见问题、影响和无法确认之处。
