# 虚构展馆教学页：正确资料与视觉目标（E21 测试）

本任务是视觉教学攻略素材检查。所有页面均为虚构测试资料，由程序渲染，不对应真实展馆、真实文物或真实旅行候选；不属于任何旅行行程，不检查作息、预约、交通。

## 唯一资料依据

- 展馆四站按单向顺序相连：南门 → 青铜展区 → 陶器展区 → 北门。
- 虚构展品名称是“三足器甲”。
- 三足器甲具有且仅具有三足、两耳、圆腹，无铭文。
- 全貌与局部应当表现同一器物；局部图的引线应当从全貌上对应的部件出发。
- 讲解只涉及上述造型，不提供年代、历史、用途等事实。

## 目标

手机可读的 3:4 竖版中文图文教学页，标明“虚构展馆测试页”。页面包含：可见路线示意、四站名称与方向关系、器物全貌、同一器物的双耳局部及其引线、数足／看耳／看腹三个观察模块（含小图与说明），文字约 200 字。

路线图像与文字应有明确对应；部件数量与引线位置符合资料；中文准确、字形正确、正文可辨；同级模块标题字号与字体风格协调；局部无妨碍观察的涂抹、接缝或遮挡。图文融合，允许使用合适的文本框；构图差异或文本框本身不是缺陷。

审核以实际 PNG 所见为依据，区分明确可见问题、影响及无法确认之处。
